## Still not a production launch sign-off

- **Privacy disclosure: unresolved readiness issue.** `/privacy` still describes a fictional preview, says no email/SMS is sent, and explicitly says the full privacy policy and retention details are unpublished. That copy is not suitable evidence of a finished client-facing policy. It needs the actual operating/retention/support details and review; this audit did not invent legal commitments. Production wording accuracy: 5/10 until resolved.
- **Live providers: not run.** No live Resend acceptance/inbox receipt, Connexus handset delivery/webhook/charge, real Google OAuth or Stripe transaction was attempted. Local and mock successes do not certify those connections or their production configuration.
- **Production backup: unverified.** The local restore archive passed eight checks, but it was synthetic and was not retained as a production backup. Current production archive freshness, retention, encryption and a restore of a real approved backup still need evidence. The local operator correctly displays Unknown when that evidence is missing.
- **Device and accessibility limits: untested.** Physical iOS/Safari, Android Chrome, assistive-technology journeys, a full WCAG audit, load testing and penetration testing were not completed. Chrome phone emulation and targeted contrast/focus checks passed.
- **Lint: unavailable.** This repo has no configured lint script, ESLint configuration or ESLint dependency. `npm test` remains a placeholder. The real existing QA runner, independent TypeScript check and optimized Next build were run instead; no lint pass is claimed.
- **Legacy harnesses: not run as-is.** The old staging-only pilot-operations harness expects a dedicated staging operator/database and restore evidence row. No hosted staging site was created. Current local operator, beta/support queue, restoration and access checks passed separately. Superseded manual-approval signup fixtures were not used to restore old behavior.
